## STACK POR TIER

### TIER ECO
- **Pedidos WA:** Business App + grupo interno organizado
- **Reservas:** Cal.com gratis o link directo a WhatsApp
- **Redes:** Canva + manual (gratis)
- **Ads:** Meta local $300-500/mes
- **Reseñas:** Google My Business manual
- **Total:** $0/mes (solo ads)

### TIER PRO
- **Pedidos:** Shopify ($39/mes) para tienda + WhatsApp Cloud API
- **Reservas:** OpenTable o Cal.com Pro
- **Programación:** Buffer ($6/mes) o Later
- **Ads:** Meta + Google Maps + presupuesto $700-2,000/mes
- **Email:** Klaviyo para clientes recurrentes
- **CRM:** Airtable Team
- **Total tools:** $90-150/mes

### TIER PREMIUM (cadenas o restaurantes >$50K/mes)
- **POS integrado:** Toast · Lightspeed (varía mucho por país)
- **Delivery propio:** integración con Rappi · Didi · Uber Eats vía API
- **Loyalty:** programa de puntos custom
- **BI:** dashboards de ventas por plato, por hora, por día
- **Total:** $500-2,500/mes
