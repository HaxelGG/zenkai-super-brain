## Reglas

- **Fuentes:** subir solo si tienen licencia comercial. Si no, comprar (APOLLO con HIVE).
- **Fotos de personas:** consentimiento por escrito archivado (especialmente menores en sectores como educación o salud).
- **Logos:** siempre en vector + raster + favicon · no usar JPG de baja resolución.
- **Originales en alta resolución** siempre. La compresión se hace en pipeline, no a la fuente.
