# /reportes
## Histórico de reportes para [CLIENTE_NOMBRE]

Cada reporte semanal y mensual se genera con el template `templates/template-reporte-cliente.md` y se guarda aquí.

## Convención de nombres

- **Semanales:** `2026-W18-reporte-semanal.md`
- **Mensuales:** `2026-05-reporte-mensual.md`
- **Trimestrales (si aplica):** `2026-Q2-reporte-trimestral.md`

## Generación

Los reportes semanales se generan automáticamente por `workflow-reporte-semanal.md` los lunes 9:00 AM.
Los mensuales y trimestrales se generan manualmente por el owner + ARES-REPORT con datos consolidados.

## Compartir con cliente

- Email con PDF + link
- WhatsApp con link al Notion del cliente (versión visible)
- Notion del cliente actualizado

## Retención

Mantener todos los reportes mientras el contrato esté activo.
Al terminar contrato: archivar 1 año antes de eliminar (según cláusula 8 contrato).
